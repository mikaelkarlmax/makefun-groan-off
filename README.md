## How it works

`main.ts` writes the joke above — exactly one line, 89 characters — to `/output/entry.txt` and prints it to the console. Nothing else is needed: no data, no network, just the line.

The joke is original, written for this bounty. It stays well inside the gate (1–140 characters): 89 characters, one line, no trailing newline.
